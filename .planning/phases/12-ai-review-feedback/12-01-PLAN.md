<objective>
Build the AI-assisted admin verification review flow. When an admin opens `/admin/verification/[id]`, the page triggers a GitHub scan via Claude Haiku (OpenRouter), then pre-fills the admin review form with the AI's recommendation, confidence, pre-checked rejection reasons, and score suggestion. Admin overrides are logged in `VerificationReview.aiSummary` for EU AI Act audit trail.

Purpose: Reduce admin review time to ~45 seconds by eliminating manual GitHub profile inspection.
Output: `POST /api/engineer/github-scan`, `GITHUB_ANALYSIS_PROMPT` in ai-prompts.ts, AI recommendation banner + pre-filled review form in admin UI.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin browser → /api/engineer/github-scan | Admin-only route; untrusted HTTP body with engineerId |
| /api/engineer/github-scan → GitHub API | External fetch; response may be malformed or adversarial |
| /api/engineer/github-scan → OpenRouter | Prompt injection possible via GitHub repo descriptions |
| AdminReviewForm → /api/admin/verification/[id] | Admin-submitted form data including overrideReason text |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01-01 | Spoofing | POST /api/engineer/github-scan | mitigate | Verify Auth.js session + admin role check before processing; reject 401 if no session, 403 if not admin |
| T-12-01-02 | Tampering | engineerId in request body | mitigate | Validate with `z.string().cuid()` — reject non-cuid values; look up engineer in DB to confirm existence |
| T-12-01-03 | Information Disclosure | GitHub API token in headers | mitigate | Use `GITHUB_TOKEN` env var only; never log token; token is optional (unauthenticated GitHub API = 60 req/hr is sufficient for low admin volume) |
| T-12-01-04 | Injection | Prompt injection via GitHub repo names/descriptions | mitigate | Strip HTML and limit GitHub data to `inputSnapshot` fields (no raw description text); `JSON.stringify(inputSnapshot)` with only typed fields (repos count, languages, lastCommit, starCount) — no free-text from repos sent to AI |
| T-12-01-05 | Denial of Service | OpenRouter API call cost | mitigate | Rate limit to 5 req/min per IP; admin-only auth gate means public cannot trigger paid AI calls |
| T-12-01-06 | Elevation of Privilege | Non-admin accessing github-scan route | mitigate | Check `session.user.role === 'ADMIN'` (or isAdmin flag per Phase 9 model); return 403 Forbidden |
| T-12-01-07 | Tampering | overrideReason stored in aiSummary | accept | Free text field, admin-controlled; sanitize to max 500 chars; no HTML injection risk (stored as JSON string, not rendered as HTML) |
| T-12-01-08 | Repudiation | AI recommendation vs admin decision | mitigate | Full aiSummary including AI output + overrideReason persisted in VerificationReview.aiSummary — constitutes EU AI Act audit trail |
</threat_model>
