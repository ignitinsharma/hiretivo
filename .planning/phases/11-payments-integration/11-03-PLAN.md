**Replace with:**
```typescript
if (user.stripeCustomerId) {
  try {
    // Find active subscription for this user
    const subscriptions = await stripe.subscriptions.list({
      customer: user.stripeCustomerId,
      status: "active",
      limit: 1,
    });
    
    if (subscriptions.data.length > 0) {
      await stripe.subscriptions.cancel(subscriptions.data[0].id, {
        prorate: true,
      });
    }
  } catch (error) {
    console.error("Failed to cancel Stripe subscription:", error);
    // Don't block deletion — per D-22 / error handling note
  }
}
```

**Add the import** at the top of the file:
```typescript
import { stripe } from "@/lib/stripe";
```

**Key implementation details** (per D-22):
- Use `stripe.subscriptions.cancel()` with `prorate: true`
- Find the active subscription first via `stripe.subscriptions.list()` — the user may have no active sub (already canceled)
- If no active subscription found, skip cancellation gracefully
- The try/catch already wraps this — don't block deletion if Stripe cancellation fails
- Keep the existing rate limiter and soft-delete logic unchanged
- Keep the existing flow: auth check → rate limit → get user → cancel stripe (new) → soft delete user → return success

**Other notes from CONTEXT.md**:
