<threat_model>
- Webhook signature verification: stripe.webhooks.constructEvent rejects payloads without valid STRIPE_WEBHOOK_SECRET signature — returns 400 on invalid signature. Prevents forged subscription events.
- Auth + role gate on checkout and portal routes: session required (401) + UserRole.RECRUITER only (403). Seekers and unauthenticated users cannot create checkout or portal sessions.
- userId integrity: Checkout Session metadata.userId is set server-side from the authenticated session — never from client input. Webhook reads metadata.userId to link subscription to the correct user.
- Raw body requirement: webhook route uses request.text() before any parsing. Next.js body parser must not consume the body first or stripe.webhooks.constructEvent will fail silently.
- Rate limiting on checkout (5/min per user) and portal (10/min per user) to prevent session-creation abuse.
</threat_model>

1. **Create `src/app/api/stripe/webhook/route.ts`** (per D-17, D-20, D-21):

   This is a critical route that handles ALL Stripe webhook events. Implementation:

   ```typescript
   import { headers } from "next/headers";
   import { NextResponse } from "next/server";
   import { stripe } from "@/lib/stripe";
   import { STRIPE_PRICE_TO_PLAN } from "@/constants/stripe";
   import { PlanTier } from "@/constants/enums";
   import { prisma } from "@/lib/prisma";
   import type Stripe from "stripe";
   ```

   **CRITICAL**: This route MUST use raw body parsing. Disable Next.js body parser:
   ```typescript
   export const runtime = "nodejs";  // Required for raw body access
   // Next.js 14+ does NOT require explicit body parser config
   // Use request.text() to get raw body for signature verification
   ```

   Flow:
   - Read raw body: `const body = await request.text()`
   - Get signature: `const signature = headers().get("stripe-signature")`
   - If no signature → return 400
   - Verify webhook: `const event = stripe.webhooks.constructEvent(body, signature, process.env.STRIPE_WEBHOOK_SECRET!)`
   - If verification fails → return 400 "Invalid signature"
   - Switch on `event.type`:
     
     **case "checkout.session.completed":**
     - Extract `session` from `event.data.object`
     - Get userId from `session.metadata.userId` (set in checkout route)
     - Get `subscription` from Stripe: `const subscription = await stripe.subscriptions.retrieve(session.subscription as string)`
     - Get `stripePriceId` from `subscription.items.data[0].price.id`
     - Determine `plan` from `STRIPE_PRICE_TO_PLAN[stripePriceId]` or fallback to `PlanTier.PRO`
     - Get `stripeCustomerId` from `session.customer`
     - Prisma transaction (`prisma.$transaction`):
       1. Upsert Subscription: `prisma.subscription.upsert({ where: { stripeSubscriptionId: subscription.id }, create: { stripeSubscriptionId: subscription.id, stripePriceId, status: "ACTIVE", currentPeriodStart: new Date(subscription.current_period_start * 1000), currentPeriodEnd: new Date(subscription.current_period_end * 1000), cancelAtPeriodEnd: subscription.cancel_at_period_end, userId }, update: { stripePriceId, status: "ACTIVE", currentPeriodStart: ..., currentPeriodEnd: ..., cancelAtPeriodEnd: ... } })`
       2. Update User: `prisma.user.update({ where: { id: userId }, data: { plan, stripeCustomerId } })`
     
     **case "customer.subscription.updated":**
     - Extract subscription from event data
     - Get userId from subscription metadata OR look up via `prisma.subscription.findUnique({ where: { stripeSubscriptionId: subscription.id } })` → then get userId
     - Get `stripePriceId` from `subscription.items.data[0].price.id`
     - Determine `plan` from `STRIPE_PRICE_TO_PLAN` or fallback to `PlanTier.PRO`
     - Prisma transaction:
       1. Update Subscription: set `status` = "ACTIVE" (if not canceled/past_due), `currentPeriodStart`, `currentPeriodEnd`, `cancelAtPeriodEnd`, `stripePriceId`
       2. Update User plan if the price changed
     
     **case "customer.subscription.deleted":**
     - Extract subscription from event data
     - Find existing subscription record by `stripeSubscriptionId`
     - Prisma transaction:
       1. Update Subscription: `status` = "CANCELED", `cancelAtPeriodEnd` = true
       2. Update User: `plan` = PlanTier.FREE
     
     **case "invoice.payment_failed":**
     - Extract invoice from event data
     - Get subscription ID from `invoice.subscription`
     - If subscription exists: find by stripeSubscriptionId
     - Update Subscription status to "PAST_DUE"
     - Do NOT change User.plan yet (grace period)
     
     **default:** Log the unhandled event type, return 200
   
   - All DB operations in each handler must be wrapped in `prisma.$transaction()` for atomicity (per D-20)
   - Return 200 for all successfully processed events (including unhandled types)
   - Return 400 only for invalid signatures
   - Wrap the entire handler in try/catch: if any error, log it and return 500 (Stripe will retry)
   
   - Add rate limiting: 100 req/min per IP for webhook endpoint (higher limit since Stripe sends many webhooks)
