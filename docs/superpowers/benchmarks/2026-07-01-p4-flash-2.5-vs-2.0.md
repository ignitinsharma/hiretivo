# Phase 4 Model Benchmark — Gemini 2.5 Flash vs Gemini 2.5 Flash-Lite

**Date run:** 2026-07-03 · **Script:** `scripts/apply-ai/benchmark-flash.ts` (`pnpm exec tsx -r dotenv/config scripts/apply-ai/benchmark-flash.ts dotenv_config_path=.env.local`)

## Scope change from the plan (read this first)

The plan asked to benchmark **Gemini 2.5 Flash vs Gemini 2.0 Flash**. Verified live on 2026-07-03:

- Direct Gemini API (`gemini-2.0-flash`): `400` with no body.
- OpenRouter (`google/gemini-2.0-flash-001`): `404 No endpoints found for google/gemini-2.0-flash-001`.

Google shut down Gemini 2.0 Flash on **2026-06-01** (confirmed via web search — see sources below). The model named in the design doc/plan no longer exists to benchmark against. **Gemini 2.5 Flash-Lite** — the real, currently-live cheaper tier — replaces it as the comparison target. This serves the plan's actual intent ("benchmark and downshift if quality holds") using a model that's actually purchasable today.

Sources: [Gemini 2.0 Flash — Artificial Analysis](https://artificialanalysis.ai/models/gemini-2-0-flash) (deprecation noted), [Gemini API Pricing 2026 — aifreeapi.com](https://www.aifreeapi.com/en/posts/gemini-api-pricing-2026).

## Method

- 3 representative real JDs: worldwide-remote (Supabase-style), US-only (Stripe-style), senior/staff (Linear-style) — each with distinct required/preferred skills.
- 1 sample seeker profile (8 YOE backend engineer, real skills/companies fixed in the script) run through both `buildResumeOptimizeMessages` and `buildCoverLetterMessages`.
- Ran via **OpenRouter** (this env's `AI_PROVIDER`), model ids `google/gemini-2.5-flash` and `google/gemini-2.5-flash-lite`. OpenRouter returns real per-call `usage.cost` in USD — used directly instead of a static pricing table (the design doc's own §6 table is already stale re: 2.0 Flash).
- Checks per run: latency, output tokens, cost, `parseResumeDocument` success, and a fabrication check (every `experience[].company` and `skillGroups[].skills` entry must appear in the real profile — anything else is a fabrication).

## Results (n=3 JDs per model)

| Model | Avg resume latency | Avg cover latency | Avg cost/job (resume+cover) | Parse success | Fabrication-free | Cover non-empty |
|---|---|---|---|---|---|---|
| `google/gemini-2.5-flash` | 3251 ms | 2064 ms | **$0.00227** | 3/3 | 3/3 | 3/3 |
| `google/gemini-2.5-flash-lite` | 2097 ms | 1583 ms | **$0.00048** | 3/3 | 3/3 | 3/3 |

Raw per-run data (JSON lines) captured in the script's stdout; re-run the script to regenerate.

## Recommendation

**Ship `google/gemini-2.5-flash-lite` as the prod `AI_MODEL` default.** At this sample size (n=3) it matched 2.5 Flash on every structural/honesty check (100% parse success, 0% fabrication, always produced a non-empty cover letter) while running ~35% faster and **~4.7× cheaper** ($0.00048/job vs $0.00227/job).

**Caveat:** n=3 with a rule-based check (structural parse + fabrication-free), not a human/LLM-judge quality read on prose fluency, tailoring nuance, or ATS-keyword weighting quality. Given both models cleared every hard check, Flash-Lite is the reasonable default; monitor real user output quality post-launch and fall back to `google/gemini-2.5-flash` via the `AI_MODEL` env var if seeker-reported quality issues emerge — no code change needed for that fallback.

**Cost-per-job vs the design doc's Ladder A (§6):** at $0.00048/job, even MAX (1000 credits/mo) costs ~$0.48/mo in AI spend against $19/mo revenue — well inside the "healthy margins" the design doc targeted, and meaningfully better than the $0.010/job (2.5 Flash) or even the original $0.002/job (2.0 Flash, now dead) estimates it was built around.

## Prod env value

```
AI_PROVIDER=openrouter
AI_MODEL=google/gemini-2.5-flash-lite
```

(A future Gemini-direct migration, per the design doc's "no OpenRouter markup" preference, would use the bare id `gemini-2.5-flash-lite` with `AI_PROVIDER=gemini` — not benchmarked here since this env's `GEMINI_API_KEY` is a placeholder, not a live credential. OpenRouter's ~10% markup is a known, accepted tradeoff until that's set up.)
