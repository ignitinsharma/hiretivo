## Goal

Let a seeker paste **any** job URL (or raw JD text) that Hiretivo doesn't already ingest, turn it into a
structured JD, persist it as an `Application` with `source = PASTED_LINK`, `externalJobUrl = <the URL>`,
`jobId = null`, and route the seeker straight into the existing **Phase-5 assisted-apply wizard** — the same
wizard reached from an internal job. One "Add your own link" entry point; graceful degradation when the URL is
un-fetchable (LinkedIn / Indeed login-walls, JS-only pages) via a **manual-paste** fallback.

## Architecture

```
Seeker UI (seeker/applications or dashboard entry)
  └─ "Add your own link" card  ──click──▶  AddLinkModal (URL input + optional JD paste textarea)
                                                │  submit
                                                ▼
                             POST /api/seeker/apply/from-link  (Zod + rate-limit + auth)
                                                │
                                                ▼
                        src/lib/apply/jd-fetch.ts :: fetchJdFromLink(url, pastedText?)
                          1. detectAtsFromUrl(url)  ──known ATS──▶ reuse ats/normalizers/* (boardToken + id)
                          2. else generic HTML fetch + extract  ──thin/blocked──▶ AI fallback (openrouter)
                          3. fetch blocked / empty  ──────────────▶ needsManualPaste: true  (UI re-prompts)
                          4. pastedText provided    ──────────────▶ AI-structure the pasted JD, skip fetch
                                                │  ParsedJd
                                                ▼
                     create Application(source=PASTED_LINK, externalJobUrl=url, jobId=null,
                                        title/description/skills from ParsedJd)
                                                │  { data: { applicationId } }
                                                ▼
                        client router.push(`/dashboard/applications/${applicationId}`)  (Phase-5 wizard)
```

`jd-fetch.ts` is **server-only** (uses `fetch` + `openrouter`; import in the route, never in a client component).
It reuses `normalizeGreenhouseJob` / `normalizeLeverJob` / `normalizeAshbyJob` where a URL maps to a known ATS
board + posting id, so ATS parsing logic is **not duplicated** (Golden Rule 1).

**Interfaces (exact)**

```ts
/* Result of matching a pasted URL against a known ATS board. */
export interface AtsUrlMatch {
  ats: AtsSource;
  boardToken: string;      // e.g. "anthropic"
  postingId: string | null; // ATS job id parsed from the URL path, when present
  company: AtsCompany | null; // registry entry if the boardToken is one we track
}

/*
 * detectAtsFromUrl
 * Maps a public job-posting URL to a known ATS (greenhouse/lever/ashby) + board token + posting id.
 * @param rawUrl - the URL the seeker pasted
 * @returns AtsUrlMatch when the host is a recognised ATS domain, else null
 */
export function detectAtsFromUrl(rawUrl: string): AtsUrlMatch | null
```

**Host patterns (real)**
- Greenhouse: `boards.greenhouse.io/<token>/jobs/<id>`, `job-boards.greenhouse.io/<token>/jobs/<id>`, `boards.eu.greenhouse.io/...`

- Ashby: `jobs.ashbyhq.com/<token>/<uuid>`

**Steps**
- [ ] Parse with `new URL(rawUrl)` in a try/catch (invalid URL → return null). Lowercase the host.
- [ ] Match host suffix → `AtsSource`; split `pathname` segments to extract `boardToken` (first segment) and `postingId` (segment after `jobs` for greenhouse, second segment for lever/ashby).
- [ ] Look up `COMPANY_REGISTRY.find(c => c.ats === ats && c.boardToken === boardToken)` for `company` (may be null — pasted board we don't track is still valid).

### Task 4 — `src/lib/apply/jd-fetch.ts` — the fetch+parse orchestrator

**Files**
- `src/lib/apply/jd-fetch.ts` (new)

This is the load-bearing module. Its return type is **consumed verbatim by the wizard-feeding route (Task 6)**.

**Interfaces (exact — the wizard/route contract)**
```ts
import { AtsSource } from '@/constants/enums';

/* Which path produced the ParsedJd (or why parsing could not complete). */
export enum JdParseStrategy {
  ATS = 'ATS',                 // matched a known ATS API
  GENERIC_HTML = 'GENERIC_HTML', // generic fetch + heuristic extract
  AI = 'AI',                   // AI structured the fetched HTML / pasted text
  MANUAL_PASTE = 'MANUAL_PASTE', // built from seeker-pasted JD text
}

/* Normalised JD ready to persist as a PASTED_LINK Application and feed the wizard. */
export interface ParsedJd {
  title: string;
  company: string | null;
  description: string;       // plain text, non-empty on success
  skills: string[];          // matched Skill.name values (may be empty)
  strategy: JdParseStrategy;
  atsSource: AtsSource | null;
}

/* Discriminated result: either a usable JD, or a signal that the UI must ask for manual paste. */
export type JdFetchResult =
  | { ok: true; jd: ParsedJd }
  | { ok: false; needsManualPaste: true; reason: string };

/*
 * fetchJdFromLink
 * Turns a pasted job URL (or pasted JD text) into a ParsedJd, or signals that manual paste is required.
 * @param url        - the job-posting URL the seeker pasted (used for ATS detection + provenance)
 * @param pastedText - optional raw JD text; when present, fetch is skipped and this is AI-structured (MANUAL_PASTE)
 * @param skills     - the Skill catalogue rows for skill matching (id + name), loaded once by the caller
 * @returns JdFetchResult — ok:true with a ParsedJd, or ok:false needsManualPaste for the UI to re-prompt
 */
export async function fetchJdFromLink(
  url: string,
  pastedText: string | null,
  skills: Array<{ id: string; name: string }>,
): Promise<JdFetchResult>
```

**Steps**
- [ ] **Manual-paste short-circuit:** if `pastedText` is non-empty, call the AI extractor on `pastedText`, run `extractSkillsFromText` (from `@/lib/ats/skill-extractor`) over `title + description`, return `{ ok:true, jd: { strategy: MANUAL_PASTE, atsSource: null, ... } }`. If AI still yields empty description, return `{ ok:false, needsManualPaste:true, reason:'Could not read the pasted job description.' }`.
- [ ] **ATS path:** `const match = detectAtsFromUrl(url)`. If matched, fetch that board via the existing normalizer fetchers (`fetchGreenhouseJobs`/`fetchLeverJobs`/`fetchAshbyJobs` take a `boardToken`) and select the posting whose `atsSourceId === match.postingId` (fallback: first posting if id absent). Map its `NormalizedJob` → `ParsedJd` (`title`, `company=companyName`, `description`, `skills=skillMatches`, `strategy=ATS`, `atsSource=match.ats`). If the board fetch fails or the posting isn't found, fall through to the generic path.
- [ ] **Generic HTML path:** `fetch(url, { headers: { 'User-Agent': 'Hiretivo/1.0 (+https://hiretivo.com)' }, redirect: 'follow', signal: AbortSignal.timeout(8000) })`. On non-OK, or on a known login-wall host (linkedin.com, indeed.com, glassdoor.com), or on `content-type` not `text/html` → `{ ok:false, needsManualPaste:true, reason:'This site blocks automated reading — paste the job description instead.' }`. On OK, `stripHtml(body)`; if the stripped text is < 200 chars (JS-only shell) → manual-paste signal.
- [ ] **AI structuring of generic HTML:** feed stripped text (truncated 8000 chars) to `buildJdExtractMessages` → `openrouter.chat.completions.create({ model: getAIModel(), ...JD_EXTRACT_CONFIG, response_format: { type: 'json_object' }, messages: [{ role: AiMessageRole.SYSTEM, content: system }, { role: AiMessageRole.USER, content: user }] })`. Parse with `JdExtractOutputSchema` (strip code fences defensively, as `suggest-skills` does). Empty description → manual-paste signal. Merge AI `skills` with `extractSkillsFromText` matches (dedupe). `strategy = GENERIC_HTML` if the heuristic alone sufficed, else `AI`.
- [ ] Wrap the whole body in try/catch → any thrown error becomes `{ ok:false, needsManualPaste:true, reason:'We could not read that link. Paste the job description to continue.' }` (never throw to the route → no 500 from a bad URL).
- [ ] Doc-comment every helper. No `console.log`.
- [ ] Verify: `pnpm tsc --noEmit`, `pnpm eslint .`.
- [ ] `git commit -m "feat(pivot): add jd-fetch orchestrator (ATS reuse + generic + AI + manual-paste)

Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>"`
