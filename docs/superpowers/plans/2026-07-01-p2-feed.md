# Phase 2 — Match-Ranked Feed + Filters (`p2-feed`)

> Part of the Hiretivo "apply-faster" pivot v3. Spine: `1a → 1b → 1c → 2 → 3a …`.
> This plan is written just-in-time before Phase 2. Reference the canonical decisions in
> `~/.claude/projects/-Users-nitinsharma-Documents-personal-hiretivo/memory/project_pivot_v3_apply_tool.md`.

## Goal

Ship the seeker's core surface: a dedicated **match-ranked job feed** with a full filter bar and a
polished dashboard "Top matches" row. This is **differentiator #1** — the feed is ordered by match %
(reusing `src/lib/match.ts`), every card shows a match ring + skills chips, and a low-match job shows a
**credit warning hint** before Apply (the seeker is about to "spend a credit" on a job they are unlikely to
land). Apply / Pass wire into the existing saved-jobs + dismissed-jobs APIs. A detail drawer reuses
`JobDetailSidebar`. Stale jobs get a light-touch "posted X ago" + "may be closed" flag.

Phase 2 does **not** consume real AI credits (that is Phase 8). The credit warning here is a UI-only nudge
driven by match score, wired so Phase 5/8 can attach real consumption later.

## Architecture

- **New module** `src/modules/seeker/feed/` — the home of all feed types, query hooks, filter state, and
  feed-specific components. Today the feed is consumed inline by
  `src/modules/seeker/dashboard/components/RecommendedJobsList.tsx` via the bare `useFeed()` hook
  (`src/hooks/use-feed.ts`, queryKey `["seeker-feed"]`, no filters). Phase 2 introduces a filter-aware hook
  keyed `["feed", filters]` and a dedicated `/seeker/feed` page; the dashboard keeps a compact "Top matches"
  row that reuses the same module.
- **API**: extend the existing `GET /api/seeker/feed` (`src/app/api/seeker/feed/route.ts`) to accept and apply
  the full filter set. The route is already match-ranked, cursor-paginated, and rate-limited
  (`feedRateLimiter`, 30/min per user). We widen `feedFilterSchema` (`src/lib/validations/match.ts`) and the
  `Prisma.JobWhereInput` builder — no new endpoint.
- **Cards**: reuse `src/components/shared/JobCard.tsx` + `SeekerJobBaseCard.tsx` (skills chips + match pill
  already exist). Add a **match ring** (new shared component — none exists today) and a **credit-warning
  banner** slot. Apply/Pass reuse `useUIStore().openApplyModal(...)` (apply) and the dismiss mutation (pass).
- **Detail drawer**: a new client `FeedJobDrawer` that renders `JobDetailSidebar`
  (`src/modules/jobs/components/JobDetailSidebar.tsx`) inside a shadcn `Sheet`; "View original posting" links
  to `externalApplyUrl`.
- **State**: filter values live in the URL (`useSearchParams`) so the feed is shareable/back-button-safe;
  TanStack Query key is `["feed", filters]`. Save state derives from `["seeker-saved-jobs"]` (existing
  convention — never invalidate feed on save).

  ```ts
  import { z } from 'zod';
  import {
    JOB_TYPE_VALUES,
    WORK_TYPE_VALUES,
    LOCATION_CLASS_VALUES,
    EXPERIENCE_BAND_VALUES,
  } from '@/constants/enums';

  /* feedFilterSchema
   * Validates seeker feed query params (client + server). All fields optional except paging defaults.
   * `companies` arrives as a comma-joined string and is split to a trimmed non-empty array. */
  export const feedFilterSchema = z.object({
    cursor: z.string().optional(),
    limit: z.coerce.number().min(1).max(50).default(10),
    recentOffset: z.coerce.number().min(0).optional(),
    // Free-text search across title + description
    search: z.string().trim().max(100).optional(),
    // Workplace (REMOTE/HYBRID/ONSITE)
    workType: z.enum(WORK_TYPE_VALUES).optional(),
    // Location class (worldwide/us-only/emea/india/onsite)
    locationClass: z.enum(LOCATION_CLASS_VALUES).optional(),
    // Comma-joined company names → array
    companies: z
      .string()
      .optional()
      .transform((v) =>
        v ? v.split(',').map((s) => s.trim()).filter(Boolean) : undefined,
      ),
    // Max experience band the seeker will consider
    experienceMax: z.enum(EXPERIENCE_BAND_VALUES).optional(),
    // Role bucket → Job.category
    role: z.string().trim().max(80).optional(),
    // Sponsors visa
    visaSponsored: z.coerce.boolean().optional(),
    // Employment type → Job.jobType (FULL_TIME/PART_TIME/CONTRACT/INTERNSHIP)
    employmentType: z.enum(JOB_TYPE_VALUES).optional(),
    // Legacy alias kept for backward compat with existing callers
    jobType: z.enum(JOB_TYPE_VALUES).optional(),
    location: z.string().optional(),
  });
  export type FeedFilterInput = z.input<typeof feedFilterSchema>;
  export type FeedFilterParsed = z.output<typeof feedFilterSchema>;
  ```
- [ ] In `src/app/api/seeker/feed/route.ts`, destructure the new fields from `parsed.data` and extend the
  `feedFilterWhere: Prisma.JobWhereInput` builder (used by BOTH the recent-offset flow and the matched flow):
  ```ts
  const {
    cursor, limit, recentOffset,
    search, workType, locationClass, companies,
    experienceMax, role, visaSponsored, employmentType, jobType,
  } = parsed.data;

  const effectiveJobType = employmentType ?? jobType; // employmentType wins

  const feedFilterWhere: Prisma.JobWhereInput = {
    status: JobStatus.OPEN,
    id: { notIn: [...appliedJobIds, ...dismissedJobIds] },
  };
  if (effectiveJobType) feedFilterWhere.jobType = effectiveJobType as PrismaJobType;
  if (workType) feedFilterWhere.workType = workType as PrismaWorkType;
  if (locationClass) feedFilterWhere.locationClass = locationClass;
  if (visaSponsored) feedFilterWhere.visaSponsored = true;
  if (role) feedFilterWhere.category = { equals: role, mode: 'insensitive' };
  if (companies && companies.length > 0) {
    feedFilterWhere.companyName = { in: companies };
  }
  if (experienceMax) {
    // Job.experienceLevel is free-form; admin jobs use entry|mid|senior.
    // "Max" = include this band and anything lower (entry ⊂ mid ⊂ senior for filtering purposes).
    const band = EXPERIENCE_LADDER[experienceMax]; // e.g. senior → [entry, mid, senior]
    feedFilterWhere.experienceLevel = { in: band };
  }
  if (search) {
    feedFilterWhere.OR = [
      { title: { contains: search, mode: 'insensitive' } },
      { description: { contains: search, mode: 'insensitive' } },
    ];
  }
  ```

  ```ts

  'use client';
  import { useInfiniteQuery } from '@tanstack/react-query';
  import { seekerService, type SeekerFeedResponse } from '@/services/seeker.service';
  import type { FeedFilters } from '@/modules/seeker/feed/types/feed.types';

  const PAGE_SIZE = 10;

  /* feedQueryKey — stable array key for the filter-aware feed. */
  export function feedQueryKey(filters: FeedFilters): ['feed', FeedFilters] {
    return ['feed', filters];
  }

  /* useFeedQuery
   * Filter-aware, cursor-paginated seeker feed. Match-ranked server-side.
   * @param filters - active FeedFilters (from URL)
   * @returns TanStack useInfiniteQuery result over SeekerFeedResponse pages. */
  export function useFeedQuery(filters: FeedFilters) {
    return useInfiniteQuery<SeekerFeedResponse>({
      queryKey: feedQueryKey(filters),
      queryFn: ({ pageParam }) =>
        seekerService.getFeed({ cursor: pageParam as string | undefined, limit: PAGE_SIZE, ...filters }),
      initialPageParam: undefined as string | undefined,
      getNextPageParam: (lastPage) => lastPage.nextCursor ?? undefined,
      staleTime: 30_000,
    });
  }
  ```
