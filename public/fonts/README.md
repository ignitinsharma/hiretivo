Font files for resume style rendering.

These are open-licensed (SIL OFL) metric-compatible substitutes for proprietary fonts:

| Enum value      | Substitute   | License | Download URL                                      |
|-----------------|--------------|---------|----------------------------------------------------|
| calibri         | Carlito      | OFL     | https://fonts.google.com/specimen/Carlito          |
| georgia         | Gelasio      | OFL     | https://fonts.google.com/specimen/Gelasio          |
| garamond        | EB Garamond  | OFL     | https://fonts.google.com/specimen/EB+Garamond      |
| cambria         | Caladea      | OFL     | https://fonts.google.com/specimen/Caladea           |

Required files (Regular + Bold for each):
- Carlito-Regular.ttf, Carlito-Bold.ttf
- Gelasio-Regular.ttf, Gelasio-Bold.ttf
- EBGaramond-Regular.ttf, EBGaramond-Bold.ttf
- Caladea-Regular.ttf, Caladea-Bold.ttf

Built-in react-pdf fonts (Times-Roman, Helvetica) do not need files.
